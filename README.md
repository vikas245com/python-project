            STUDENT RESULT MANAGER
A beginner-friendly Python project that calculates student marks, percentage, grade, and pass/fail result.
Features Accepts student name and marks for three subjects.
alidates marks between 0 and 100.
Handles non-numeric input using try/except.
Calculates total marks and percentage.
Checks subject-wise pass/fail status.
Supports multiple students in one run.

Technologies Used 
Python Functions
Loops and conditional statements
Exception handling

How to Run
Install Python.
Download Student_Result_Manager.py.
Open a terminal in the file's folder.

Run:
python Student_Result_Manager.py
